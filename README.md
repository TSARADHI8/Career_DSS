# Career Decision Support System (DSS) v2.0

A full-stack web application that helps B.Tech students make data-driven career decisions using a **Machine Learning model** trained on real placement data.

## Live Demo
> Deploy to Railway and add your URL here

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend API | FastAPI (Python) |
| Database | PostgreSQL + SQLAlchemy ORM |
| Authentication | JWT (JSON Web Tokens) + bcrypt |
| ML Model | scikit-learn RandomForest (84% accuracy) |
| Frontend | HTML5 / CSS3 / Vanilla JS |

---

## Features

- **Student Registration & Login** — secure JWT-based authentication, passwords hashed with bcrypt
- **Profile Submission** — students enter skills, backlogs, projects, internships
- **ML Prediction** — RandomForest classifier gives a ranked recommendation with confidence score
- **Rule-Based DSS** — cross-validates ML output with the original rule-based scoring engine
- **Prediction History** — each student can view all past submissions
- **Admin Stats** — endpoint to view aggregate data across all students
- **Auto-generated API docs** — available at `/docs` (Swagger UI)

## Setup & Run Locally

### 1. Clone the repo
```bash
git clone https://github.com/TSARADHI8/Career_DSS.git
cd Career_DSS
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set up PostgreSQL
```sql
CREATE DATABASE career_dss;
```

### 4. Configure environment
```bash
cp .env.example .env
# Edit .env with your PostgreSQL credentials and a secret key
```

### 5. Train the ML model
```bash
python ml/train_model.py
```

### 6. Start the server
```bash
uvicorn main:app --reload
```

Open **http://localhost:8000** in your browser.  
API docs at **http://localhost:8000/docs**

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/register` | Register a new student |
| POST | `/auth/login` | Login, get JWT token |
| GET | `/auth/me` | Get current user profile |
| POST | `/predict/` | Submit profile + get ML prediction |
| GET | `/predict/history` | Get prediction history |
| GET | `/admin/stats` | Aggregate stats (all students) |

## ML Model Details

- **Algorithm:** Random Forest Classifier (100 estimators)
- **Training data:** 1000+ student placement records
- **Features:** Skill count, experience level, academic risk, placement readiness, backlogs, internships, projects
- **Accuracy:** 84% on held-out test set
- **Output:** One of — Immediate Job, Higher Studies, Skill Improvement, Wait & Improve
